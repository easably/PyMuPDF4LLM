### Consumer

Doc2Graph already stores `picture_report.truncated` and `reasons`. This response has `truncated: true` and `count: 788`, so the consumer can see that the list stopped. No new field was added.

Pictures are not required for a text request. The consumer sends `include_pictures=true` only when it indexes figures. Ids are one-time and die on restart. Fetch them from the same instance within ten minutes.

Whether Doc2Graph needs scan-page renders, vector drawings, sub-100px icons, or the later rasters past the cap of 80 is a product choice on that side. This service still returns embedded rasters only, and it stops at 80.
